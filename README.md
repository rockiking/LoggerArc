Данный модульный проект(далее будет называться логгер) создан для повышения прозрачности работы какого-либо приложения.
Функции приложения: показать как работает логгер на примере.
Для запуска данного файла в первую очередь необходимо его распаковать, для этого на скачанный зип файл нажмите правой кнопкой мыши и нажмите извлечь.
Далее выберите нужный вам путь его извлечения, извлеките.
после чего перейдите в файл и выберите Logger.sln.
В среде Visual studio нажмите F5.
Поздравляю проект запущен!!
